# تمرین ۱ — Agent استدلال محلی با Ollama

## نصب

1. [Ollama](https://ollama.com) را نصب و اجرا کنید.
2. مدل اعلام‌شده را بگیرید (نام دقیق را از مدرس بگیرید، مثلاً):

```bash
ollama pull qwen3.6:27b
```

3. پکیج Python اضافه لازم نیست (فقط کتابخانهٔ استاندارد، Python 3.9+). `requirements.txt` برای کامل بودن هست:

```bash
pip install -r requirements.txt
```

## اجرا

```bash
python main.py --input input.json --output output.json
# یا با نام مدل مشخص:
python main.py --input input.json --output output.json --model qwen3.6:27b
```

نام مدل را می‌توان با `--model` یا متغیر محیطی `OLLAMA_MODEL` داد. اگر آن نام دقیقاً نصب نباشد، برنامه شبیه‌ترین مدل نصب‌شده را (هم‌اندازه و هم‌خانواده) انتخاب می‌کند تا ارزیابی به‌خاطر اختلاف نام تگ خالی برنگردد.

ورودی یک شیء `{"id", "problem"}` است و خروجی `{"id", "answer"}`. (آرایه‌ای از چند شیء هم پذیرفته می‌شود.) خروجی همیشه JSON معتبر است؛ در بدترین حالت `answer` خالی است.

اجرای ۱۰ سؤال Public: `python run_public.py` — تست‌های بدون مدل: `python test_unit.py`

## معماری Agent (Program-of-Thought + Self-Consistency + Verifier)

حداکثر ۵ فراخوانی مدل و ۶۰۰ ثانیه برای هر مسئله (قابل تغییر با `AGENT_MAX_CALLS` و `AGENT_TIME_BUDGET`).

1. **پیش‌پردازش:** ارقام فارسی/عربی به ASCII تبدیل می‌شوند و «قرارداد خروجی» از متن مسئله استخراج می‌شود: فقط عدد صحیح، فقط یک حرف، کد N رقمی، فهرست گزینه‌های مجاز، یا الگویی مثل `Nima=<integer>, Sara=<integer>`.
2. **Solver A:** مدل مسئله را به یک برنامهٔ Python (جست‌وجوی کامل، حساب دقیق، BFS و …) تبدیل می‌کند. برنامه در پروسهٔ جدا با محدودیت زمان و فیلتر عملیات خطرناک اجرا می‌شود و خروجی چاپ‌شده — نه ادعای مدل — پاسخ است.
3. **Verifier/Repair:** اگر اجرا خطا بدهد یا خروجی با قرارداد نخواند، یک بار با متن خطا اصلاح می‌شود.
4. **Solver B:** مستقل و با دمای بالاتر دوباره برنامه می‌نویسد (Self-Consistency).
5. اگر A و B یکی باشند همان پاسخ است؛ اگر نه، **Adjudicator** با دیدن هر دو پاسخ برنامهٔ اصلاح‌شده می‌نویسد.
6. **Fallback:** اگر هیچ برنامه‌ای جواب نداد، یک فراخوانی استدلال مستقیم (CoT) پاسخ می‌دهد تا خروجی خالی نماند.
7. **Canonicalize:** برچسب‌هایی مثل `answer:`، نقطهٔ آخر، `8.0` و اختلاف حروف بزرگ/کوچک با گزینه‌های مجاز اصلاح می‌شوند.

همهٔ inference از طریق Ollama محلی (`http://127.0.0.1:11434`) است؛ هیچ API ابری استفاده نمی‌شود. حالت thinking مدل خاموش است تا زمان اجرا کوتاه بماند و خروجی JSON قابل پارس باشد. هیچ پاسخی hard-code نشده است.
